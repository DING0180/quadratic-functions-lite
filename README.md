# 二次函数互动教学网站

这是一个面向课堂投影设计的二次函数互动教学网站，使用统一的课时导航、步骤式教学流程和可交互图象，帮助学生从概念理解逐步过渡到实际问题建模。

## 主要功能

- 覆盖二次函数的概念、解析式形式、图象性质、顶点与对称轴。
- 通过动态图象探索开口方向、开口大小、最值、与坐标轴交点等性质。
- 支持一般式、顶点式之间的转换，以及近似根、区间最值和不等式图象解法。
- 提供实际问题建模：降价与利润、拱门设计等，将 Real → Math 的建模流程可视化。
- Lesson 10 和 Lesson 11 提供动态参数调节、关键点展示、Random Practice 和答案 Reveal。
- 公式使用 KaTeX 排版，图象使用统一的二次函数图象引擎，适合课堂讲解和投影演示。
- 每课采用 Previous / Next 步骤导航，答案默认隐藏，便于教师控制课堂节奏。
